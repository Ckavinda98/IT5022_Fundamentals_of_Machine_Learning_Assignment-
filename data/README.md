# Dataset Information

## Source
- Dataset: Electrical Grid Stability Simulated Dataset
- Kaggle URL: https://www.kaggle.com/datasets/avikdas567/electrical-grid-stability-and-control-simulation
- Original research: Vadim Arzamasov et al., "Towards Concise Models of Grid Stability", Communications in Computer and Information Science, 2018.

## Files
- `raw/electrical_grid_stability.csv`: Original simulation output file (10,000 samples, 14 columns).

## Variables
- `tau1` to `tau4`: Reaction time of network participants (0.5 to 10 seconds).
- `p1`: Power generated by supplier (positive nominal value).
- `p2` to `p4`: Power consumed by consumers (negative nominal values; $p_1 + p_2 + p_3 + p_4 = 0$).
- `g1` to `g4`: Price elasticity coefficients (gamma, 0.05 to 1.0).
- `stab`: Maximal real part of the characteristic differential equation root (stability indicator).
- `stabf`: System stability label (`stable` if $stab \le 0$, `unstable` if $stab > 0$).

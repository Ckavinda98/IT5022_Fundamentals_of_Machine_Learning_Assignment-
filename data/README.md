# Dataset Information

## Source
- Dataset: Electrical Grid Stability Simulated Data (UCI Machine Learning Repository, donated 15 Nov 2018)
- Original (UCI): https://doi.org/10.24432/C5PG66 — licence CC BY 4.0
- Mirror used for download (Kaggle): https://www.kaggle.com/datasets/avikdas567/electrical-grid-stability-and-control-simulation
- Dataset citation: Arzamasov, V. (2018). Electrical Grid Stability Simulated Data [Dataset]. UCI Machine Learning Repository.
- Original research: Arzamasov, V., Böhm, K. and Jochem, P. (2018). "Towards Concise Models of Grid Stability". IEEE SmartGridComm 2018, pp. 1–6. doi:10.1109/SmartGridComm.2018.8587498
- Underlying grid model: Schäfer, B. et al. (2016). "Taming instabilities in power grid networks by decentralized control". Eur. Phys. J. Special Topics 225(3), 569–582.

## Files
- `raw/electrical_grid_stability.csv`: Original simulation output file (10,000 samples, 14 columns).

## Variables
- `tau1` to `tau4`: Reaction time of network participants (0.5 to 10 seconds).
- `p1`: Power generated by supplier (positive nominal value).
- `p2` to `p4`: Power consumed by consumers (negative nominal values, -2 to -0.5 s^-2; $p_1 + p_2 + p_3 + p_4 = 0$, so `p1` is exactly redundant — UCI lists it as non-predictive).
- `g1` to `g4`: Price elasticity coefficients (gamma, 0.05 to 1.0 s^-1).
- `stab`: Maximal real part of the characteristic differential equation root (stability indicator).
- `stabf`: System stability label (`stable` if $stab \le 0$, `unstable` if $stab > 0$).
